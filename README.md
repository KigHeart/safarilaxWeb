# Safari LAX — Private Africa, Unhurried

> Designed by **Kiprop Yego, 2026** for **Safari LAX** (https://safarilax.world)

An ultra-luxury bespoke travel & safari website showcasing private, tailor-made journeys in Kenya and across Africa. Built with modern React 19, TypeScript, Tailwind CSS, Lucide icons, and editorial Cormorant Garamond typography.

---

## 🚀 How to Run Locally on Your Machine

### 1. Requirements
Ensure you have **Node.js (v18 or higher)** installed on your machine.
Check via terminal/PowerShell:
```bash
node -v
npm -v
```

### 2. Extract into your directory (`E:\SafariLax\safarilaxWeb`)
Extract the downloaded zip contents directly into your project folder.

### 3. Install Dependencies
Open your PowerShell / Terminal in that directory:
```bash
cd E:\SafariLax\safarilaxWeb
npm install
```

### 4. Start the Local Development Server
```bash
npm run dev
```
Your terminal will display:
```
  VITE v8.x.x  ready in 300 ms

  ➜  Local:   http://localhost:5173/ (or http://localhost:3000)
  ➜  Network: use --host to expose
```
Open **`http://localhost:5173`** (or the URL shown) in Chrome / Edge / Brave. The entire high-end site is 100% operational on your local machine!

### 5. Push to Your GitHub Repository
Since you have already cloned your GitHub repository (`https://github.com/KigHeart/safarilaxWeb`):
```bash
git add .
git commit -m "feat: Safari LAX full luxury website designed by Kiprop Yego 2026"
git branch -M main
git push -u origin main
```
